# Laddu Bhai Food Point

Native Kotlin + Jetpack Compose Android customer app. Package: `com.laddufoodpoint`.

Menu browsing and a basic cart/checkout demonstration are included. Checkout is not connected to a restaurant backend; no live order is transmitted or tracked.

Set repository Actions secrets: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.
